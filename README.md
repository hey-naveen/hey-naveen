## Achievements

Achievements are maintained manually in `Achievements/achievement_content.js`. Add or update an entry
there and place its certificate images in `Achievements/certificates/`; the page does not generate or
sync achievements automatically.

Use filenames in the format `YYYY-MM-DD__achievement-slug__photo-NN.jpg` (or `YYYY-MM` when the exact
day is unknown). Give different achievements different slugs, even when they share a date. Use the same
date and slug with a different photo number for additional images of one achievement. Filenames help
keep files organized; cards and image galleries are still defined explicitly in `achievement_content.js`.
